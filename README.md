# Homebrew formulas for tamentis.com projects

The following recipes are available:

    brew install tamentis/core/mdp
    brew install tamentis/core/openbsd-ksh
    brew install tamentis/core/prwd
    brew install tamentis/core/uncsv
    brew install tamentis/core/sleepuntil

Each formula installs the pinned release version by default. To build the
latest from the project's `master` branch instead, pass `--HEAD`:

    brew install --HEAD tamentis/core/prwd
